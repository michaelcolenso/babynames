How it works

Every name leaves a trail.

NobodyNamed classifies every American name by its trajectory — not just its current ranking, but where it's been and where it's heading. Using SSA birth records since 1880, we track each name's peak year, growth rate, generational shift, and vital status: Rising, Stable, Declining, Endangered, or Extinct. Search any name above to see where it lands — or browse by birth year, decade, or first letter.
